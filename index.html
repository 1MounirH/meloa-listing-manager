Meloa Listing Manager

Product Listing Management for Etsy

About the Application

Meloa Listing Manager is an application designed to create and manage Etsy draft listings using the official Etsy Open API.

Features

Bulk upload of product images, videos, titles, descriptions, tags, and other listing information.

Human Review

I personally prepare and review all product content before uploading it. The application creates draft listings for my review. I manually publish each listing on Etsy.
